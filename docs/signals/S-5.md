# 内側ループはエージェントが goal.md を active で作ることに依存していて、強制されていない

無人で 1 イテレーション回したところ、.claude/goal.md は status: done かつ round: 0 で終わり、
judge-log.jsonl が作られなかった。= goal-gate は一度も判定しておらず、内側ループが丸ごと
素通しされた。作業自体は完了していたが、検証は自己採点だけだった。

記事の 'don't let an agent self-verify' に真正面から反する状態が、実運用で発生した。

commands/loop.md の手順 5 に「必ず active で作る / 自分で done に書き換えない」を明記し、
手順 6 に round: 0 の検出を足したが、これは**エージェントへの指示であって強制ではない**。

強制する案:
- goal.md が無いまま Stop したら stop-gate 側で気づかせる(ただし goal 不要の項目もある)
- loop-run.sh が実行後に round と judge-log を検査し、0 件なら台帳に failed を書く
  (無人実行に限れば機械的に検出できる)
