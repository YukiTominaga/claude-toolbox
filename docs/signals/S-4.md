# 未追跡ファイルへの追記が無進捗検知に映らない

goal-gate の署名は git rev-parse HEAD + git diff HEAD + git status --porcelain。
未追跡ファイルは status に名前しか出ないため、既存の未追跡ファイルへ追記しても署名が変わらず
「進んでいない」と判定される。

通常運転では auto-commit が各ラウンドでコミットして HEAD が動くため表面化しない。
auto-commit が効かない構成 (main ブランチ、git 管理外、機密パス検出で中止) では
前進しているのに stalled になりうる。

対策候補: 署名に未追跡ファイルの内容ハッシュを含める
(git ls-files --others --exclude-standard -z | xargs -0 shasum)。
実際に踏むまでは入れない。

## 経過 (2026-07-25)

Q-8 として backlog に積んだ。

Q-8 で対処。署名に未追跡ファイルの内容 (cksum) を含めた。
独立検証が「git ls-files が非 ASCII パスを C クォートするため日本語名では効かない」
という環境依存の欠陥を検出し、`-z` を使う形に修正。
このマシンは core.quotePath=false なので症状が出ず、fixture 側で既定に固定して再現させている。
