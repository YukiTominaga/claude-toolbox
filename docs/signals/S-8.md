# 書き込みが部分的に失敗するとカウントが巻き戻る

hooks/stop-gate.sh の printf > "$STATE" が ENOSPC 等で失敗して空ファイルを残すと、
次回の読み取りが '' → 0 に正規化されてカウントが巻き戻り、差し戻し上限が効かなくなる。
事前チェックの : >> "$STATE" は権限しか見ておらず容量は見ない。

一時ファイル + mv にすれば原子的にできる。低頻度なので今は入れない。
