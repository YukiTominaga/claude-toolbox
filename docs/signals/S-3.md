# 「作業ツリーを覗く仕組み」はループ自身の書き込みで必ず汚染される

同じ根の問題を 3 回踏んだ:
1. auto-commit が作業ツリーを空にする → 無進捗検知の署名に HEAD を追加して解決
2. auto-commit がコミットする → 判定器の材料に git log を追加して解決
3. 判定履歴をプロジェクト内に移した → 署名と auto-commit の対象から .claude/loop/ を除外して解決

新しく「git の状態を読む仕組み」を足すときは、ループ自身の記帳が混ざらないかを先に確認すること。
将来 eval で機械的に検出できないか検討する価値がある。
