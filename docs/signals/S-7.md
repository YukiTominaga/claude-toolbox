# 台帳に行種を足すと読み側が静かに壊れる

loop-run.sh が cost 行を足したところ、loop-log.sh --recent が結果行として cost 行を返し、
S-5 の素通し検出が動かなくなった。--recent が「start 行を除外する」書き方だったため。

除外リスト方式は、行種を足すたびに全部の読み側を直す必要があり、必ずどこかで直し忘れる。
.result の有無で**選ぶ**方式に変更した。

S-3(作業ツリーを覗く仕組みはループ自身の書き込みで汚染される)と同じ形。
ループの記帳を増やすときは、既存の読み側が何を前提にしているかを先に確認すること。

## 経過 (2026-07-25)

読み側は修正済み(.result の有無で選ぶ方式)。残っているのは「行種を足すときの手順」を
どこに書くかで、まだ仕事の形になっていないため open のまま。
